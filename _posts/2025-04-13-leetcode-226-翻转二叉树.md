## 题目来源
[226. 翻转二叉树 - 力扣（LeetCode）](https://leetcode.cn/problems/invert-binary-tree/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目大意
给定一个二叉树的根节点 `root`，要求翻转这棵二叉树，并返回其根节点。翻转二叉树是指将每个节点的左右子树交换。

## 解题思路及复杂度分析
### 问题分析
题目要求翻转二叉树，即将每个节点的左右子树交换。这个问题的关键在于如何遍历二叉树并交换每个节点的左右子树。

### 方法一：递归方法
递归方法是比较直观的解法，通过递归交换每个节点的左右子树。

#### 递归逻辑
1. **递归终止条件**：如果当前节点为空，直接返回。
2. **递归逻辑**：
   - 递归交换左子树。
   - 递归交换右子树。
   - 交换当前节点的左右子树。

#### 为什么这种方法可行
- **直观性**：递归方法直接反映了翻转二叉树的定义，易于理解和实现。
- **正确性**：通过递归，可以确保每个节点的左右子树都被正确交换。

### 方法二：迭代方法（使用队列）
迭代方法通过队列来模拟递归的过程，避免递归调用的开销。

#### 迭代逻辑
1. **初始化**：使用一个队列来存储节点，初始化当前节点为根节点。
2. **迭代遍历**：
   - 弹出队列中的一个节点，交换其左右子树。
   - 如果左子节点不为空，将其加入队列。
   - 如果右子节点不为空，将其加入队列。
3. **结束条件**：当队列为空时，遍历结束。

#### 为什么这种方法可行
- **高效性**：迭代方法通过队列模拟递归过程，避免了递归调用的开销，适用于大规模数据。
- **正确性**：通过队列，可以确保每个节点的左右子树都被正确交换。

### 时间复杂度分析
- 递归方法和迭代方法的时间复杂度均为 \(O(n)\)，其中 \(n\) 是二叉树的节点数。

### 空间复杂度分析
- 递归方法的空间复杂度为 \(O(h)\)，其中 \(h\) 是二叉树的高度。
- 迭代方法的空间复杂度为 \(O(n)\)，因为队列可能存储所有节点。

## 代码
### 方法一：递归方法
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null; // 如果当前节点为空，直接返回
        // 递归交换左子树
        TreeNode left = invertTree(root.left);
        // 递归交换右子树
        TreeNode right = invertTree(root.right);
        // 交换当前节点的左右子树
        root.left = right;
        root.right = left;
        return root;
    }
}
```

### 方法二：迭代方法（使用队列）

```java
import java.util.LinkedList;
import java.util.Queue;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null; // 如果根节点为空，直接返回
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root); // 将根节点加入队列
        while (!queue.isEmpty()) {
            TreeNode current = queue.poll(); // 弹出队列中的一个节点
            // 交换当前节点的左右子树
            TreeNode temp = current.left;
            current.left = current.right;
            current.right = temp;
            // 如果左子节点不为空，将其加入队列
            if (current.left != null) queue.offer(current.left);
            // 如果右子节点不为空，将其加入队列
            if (current.right != null) queue.offer(current.right);
        }
        return root; // 返回翻转后的根节点
    }
}
```
