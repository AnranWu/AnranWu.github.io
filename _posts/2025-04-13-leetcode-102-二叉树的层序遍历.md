## 题目来源
[102. 二叉树的层序遍历 - 力扣（LeetCode）](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目大意
给定一个二叉树的根节点 `root`，要求返回其节点值的层序遍历结果。层序遍历是指逐层地，从左到右访问所有节点。

## 解题思路及复杂度分析
### 问题分析
题目要求实现二叉树的层序遍历。层序遍历是一种常见的二叉树遍历方式，其遍历顺序为：从上到下，从左到右。这个问题的关键在于如何逐层遍历二叉树并返回每层的节点值。

### 方法：层序遍历（使用队列）
层序遍历通常使用队列来实现，通过队列可以方便地逐层访问节点。

#### 层序遍历逻辑
1. **初始化**：
   - 使用一个队列来存储节点，初始化当前节点为根节点。
   - 使用一个队列来存储每个节点的深度。
   - 使用一个列表 `res` 来存储最终的层序遍历结果。
   - 使用一个临时列表 `tmp` 来存储当前层的节点值。
2. **迭代遍历**：
   - 弹出队列中的一个节点及其深度。
   - 如果当前节点的深度与上一层的深度不同，说明已经处理完一层，将当前层的节点值加入结果列表，并重置临时列表。
   - 将当前节点的值加入临时列表。
   - 如果当前节点的左子节点不为空，将其加入队列，并记录其深度。
   - 如果当前节点的右子节点不为空，将其加入队列，并记录其深度。
3. **结束条件**：当队列为空时，遍历结束。
4. **最终结果**：将最后一层的节点值加入结果列表。

#### 为什么这种方法可行
- **队列的高效性**：队列可以高效地实现逐层访问节点。
- **正确性**：通过队列，可以确保每个节点的访问顺序符合层序遍历的要求。

### 时间复杂度分析
- 层序遍历的时间复杂度为 \(O(n)\)，其中 \(n\) 是二叉树的节点数。每个节点被访问一次。

### 空间复杂度分析
- 层序遍历的空间复杂度为 \(O(n)\)，因为队列可能存储所有节点。

## 代码
```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        Queue<TreeNode> queue = new LinkedList<>(); // 用于存储节点
        Queue<Integer> queueDepth = new LinkedList<>(); // 用于存储每个节点的深度
        int nowDepth = 0; // 当前深度
        List<List<Integer>> res = new ArrayList<>(); // 存储最终结果
        List<Integer> tmp = new ArrayList<>(); // 存储当前层的节点值
        if (root == null) return res; // 如果根节点为空，直接返回空结果
        queue.offer(root); // 将根节点加入队列
        queueDepth.offer(0); // 根节点的深度为0
        while (!queue.isEmpty()) {
            TreeNode now = queue.poll(); // 弹出队列中的一个节点
            int nowD = queueDepth.poll(); // 弹出该节点的深度
            if (nowD != nowDepth) {
                // 如果当前深度与上一层深度不同，说明已经处理完一层
                res.add(tmp); // 将当前层的节点值加入结果列表
                tmp = new ArrayList<>(); // 重置临时列表
                nowDepth++; // 更新当前深度
            }
            tmp.add(now.val); // 将当前节点的值加入临时列表
            if (now.left != null) {
                queue.offer(now.left); // 如果左子节点不为空，加入队列
                queueDepth.offer(nowD + 1); // 记录左子节点的深度
            }
            if (now.right != null) {
                queue.offer(now.right); // 如果右子节点不为空，加入队列
                queueDepth.offer(nowD + 1); // 记录右子节点的深度
            }
        }
        res.add(tmp); // 将最后一层的节点值加入结果列表
        return res; // 返回最终结果
    }
}
```
