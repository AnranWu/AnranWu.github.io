## 题目来源
[169. 多数元素 - 力扣（LeetCode）](https://leetcode.cn/problems/majority-element/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目大意
给定一个大小为 \( n \) 的数组 `nums`，要求返回其中的多数元素。多数元素是指在数组中出现次数大于 \( \lfloor n/2 \rfloor \) 的元素。题目保证数组非空且总是存在多数元素。

## 解题思路及复杂度分析
### 问题分析
题目要求找到数组中的多数元素，即出现次数超过数组长度一半的元素。这个问题的关键在于如何在满足线性时间复杂度和常量空间复杂度的条件下找到这个元素。

### 方法：摩尔投票法（Boyer-Moore Voting Algorithm）
摩尔投票法是一种高效的算法，可以在 \( O(n) \) 的时间复杂度和 \( O(1) \) 的空间复杂度内找到多数元素。

#### 摩尔投票法逻辑
1. **初始化**：
   - 使用一个变量 `candidate` 来存储当前的候选元素。
   - 使用一个变量 `count` 来存储当前候选元素的计数。
2. **遍历数组**：
   - 如果 `count` 为 0，将当前元素设为候选元素。
   - 如果当前元素等于候选元素，计数加 1；否则，计数减 1。
3. **最终结果**：
   - 遍历结束后，`candidate` 中存储的就是多数元素。

#### 为什么这种方法可行
- **线性时间复杂度**：遍历数组一次，时间复杂度为 \( O(n) \)。
- **常量空间复杂度**：只使用了两个额外变量 `candidate` 和 `count`，空间复杂度为 \( O(1) \)。
- **正确性**：由于多数元素的数量超过数组长度的一半，摩尔投票法可以正确地找到这个元素。

### 时间复杂度分析
- 遍历数组一次，时间复杂度为 \( O(n) \)，其中 \( n \) 是数组的长度。

### 空间复杂度分析
- 只使用了两个额外变量，空间复杂度为 \( O(1) \)。

## 代码
```java
class Solution {
    public int majorityElement(int[] nums) {
        int candidate = 0; // 候选元素
        int count = 0; // 候选元素的计数
        for (int num : nums) {
            if (count == 0) {
                candidate = num; // 如果计数为0，将当前元素设为候选元素
            }
            count += (num == candidate ? 1 : -1); // 更新计数
        }
        return candidate; // 返回候选元素
    }
}
```
