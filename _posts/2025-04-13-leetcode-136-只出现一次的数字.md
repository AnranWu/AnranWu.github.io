## 题目来源
[136. 只出现一次的数字 - 力扣（LeetCode）](https://leetcode.cn/problems/single-number/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目大意
给定一个非空整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。要求找出那个只出现一次的元素。算法需要满足线性时间复杂度，并且只使用常量额外空间。

## 解题思路及复杂度分析
### 问题分析
题目要求找出数组中只出现一次的元素，而其他元素均出现两次。这个问题的关键在于如何在满足线性时间复杂度和常量空间复杂度的条件下找到这个唯一出现一次的元素。

### 方法：位运算（XOR）
位运算（特别是异或运算）是一种高效的方法，可以满足题目的要求。

#### 异或运算的性质
1. **交换律**：`a ^ b ^ a = b ^ (a ^ a) = b ^ 0 = b`
2. **结合律**：`(a ^ b) ^ c = a ^ (b ^ c)`
3. **自反性**：`a ^ a = 0`
4. **恒等性**：`a ^ 0 = a`

#### 位运算逻辑
1. **初始化**：使用一个变量 `res` 初始化为 0，用于存储最终结果。
2. **遍历数组**：对数组中的每个元素进行异或运算，将结果存储在 `res` 中。
3. **最终结果**：由于异或运算的性质，所有成对出现的元素在异或运算后会抵消为 0，最终 `res` 中存储的就是那个只出现一次的元素。

#### 为什么这种方法可行
- **线性时间复杂度**：遍历数组一次，时间复杂度为 \(O(n)\)。
- **常量空间复杂度**：只使用了一个额外变量 `res`，空间复杂度为 \(O(1)\)。

### 时间复杂度分析
- 遍历数组一次，时间复杂度为 \(O(n)\)，其中 \(n\) 是数组的长度。

### 空间复杂度分析
- 只使用了一个额外变量 `res`，空间复杂度为 \(O(1)\)。

## 代码
```java
class Solution {
    public int singleNumber(int[] nums) {
        int res = 0; // 初始化结果变量为0
        for (int i = 0; i < nums.length; i++) {
            res = res ^ nums[i]; // 对数组中的每个元素进行异或运算
        }
        return res; // 返回最终结果
    }
}
```
