## 题目来源
[104. 二叉树的最大深度 - 力扣（LeetCode）](https://leetcode.cn/problems/maximum-depth-of-binary-tree/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目大意
给定一个二叉树的根节点 `root`，要求返回其最大深度。二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数。

## 解题思路及复杂度分析
### 问题分析
题目要求计算二叉树的最大深度。最大深度是指从根节点到最远叶子节点的最长路径上的节点数。这个问题的关键在于如何高效地遍历二叉树并计算其深度。

### 方法一：递归方法
递归方法是比较直观的解法，通过递归计算每个子树的深度，然后取最大值。

#### 递归逻辑
1. **递归终止条件**：如果当前节点为空，返回 0。
2. **递归逻辑**：
   - 递归计算左子树的深度。
   - 递归计算右子树的深度。
   - 返回左子树和右子树深度的最大值加 1（当前节点的深度）。

#### 为什么这种方法可行
- **直观性**：递归方法直接反映了二叉树深度的定义，易于理解和实现。
- **正确性**：通过递归，可以确保每个节点的深度都被正确计算。

### 时间复杂度分析
- 递归方法的时间复杂度为 \(O(n)\)，其中 \(n\) 是二叉树的节点数。每个节点被访问一次。

### 空间复杂度分析
- 递归方法的空间复杂度为 \(O(h)\)，其中 \(h\) 是二叉树的高度。递归调用栈的深度等于二叉树的高度。

## 代码
### 方法一：递归方法
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0; // 如果当前节点为空，返回0
        // 递归计算左子树和右子树的深度，取最大值加1
        return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
    }
}
```
