  ## 题目来源
  [101. 对称二叉树 - 力扣（LeetCode）](https://leetcode.cn/problems/symmetric-tree/description/?envType=study-plan-v2&envId=top-100-liked)

  ## 题目大意
  给定一个二叉树的根节点 `root`，检查它是否轴对称。

  ## 解题思路及复杂度分析
  ### 问题分析
  题目要求判断一个二叉树是否是轴对称的。轴对称的二叉树意味着左子树和右子树在结构和值上完全对称。

  ### 方法一：递归方法
  递归方法是比较直观的解法，通过递归比较左子树和右子树的对称性。

  #### 递归逻辑
  1. **递归终止条件**：
     - 如果两个节点都为空，返回 `true`。
     - 如果一个为空而另一个不为空，返回 `false`。
     - 如果两个节点的值不相等，返回 `false`。
  2. **递归逻辑**：
     - 递归比较左子树的左节点和右子树的右节点。
     - 递归比较左子树的右节点和右子树的左节点。

  ### 方法二：层序遍历方法
  你的代码使用了层序遍历（BFS）的方法来判断二叉树是否对称。具体来说，你通过队列逐层遍历二叉树，并将每一层的节点值存储到一个数组中，然后检查该数组是否对称。

  #### 层序遍历逻辑
  1. **初始化**：
     - 使用两个队列，一个用于存储节点，另一个用于存储节点的深度。
     - 使用一个数组 `tmp` 用于存储每一层的节点值。
  2. **层序遍历**：
     - 从根节点开始，逐层遍历二叉树。
     - 对于每个节点，检查其深度是否发生变化。如果发生变化，说明已经处理完一层，需要检查当前层是否对称。
     - 如果当前层不对称，直接返回 `false`。
     - 如果当前节点为空，存储一个特殊值 `notExist`。
     - 如果当前节点不为空，存储其值，并将其左右子节点加入队列。
  3. **检查对称性**：
     - 使用 `check` 方法检查数组是否对称。如果某一层的数组不对称，返回 `false`。

  ### 为什么这种方法可行
  1. **递归方法的高效性**：递归方法可以直接比较两个子树的对称性，避免了逐层遍历的复杂性。
  2. **层序遍历的直观性**：通过层序遍历，可以逐层检查二叉树的对称性，直观且易于实现。
  3. **对称性的检查**：通过检查每一层的数组是否对称，可以确保整个二叉树的对称性。

  ### 时间复杂度分析
  - 递归方法的时间复杂度为 \(O(n)\)，其中 \(n\) 是二叉树的节点数。
  - 层序遍历的时间复杂度为 \(O(n)\)，其中 \(n\) 是二叉树的节点数。

  ### 空间复杂度分析
  - 递归方法的空间复杂度为 \(O(h)\)，其中 \(h\) 是二叉树的高度。
  - 层序遍历的空间复杂度为 \(O(n)\)，其中 \(n\) 是二叉树的节点数。

  ## 代码
  ### 方法一：递归方法
  ```java
  /**
   * Definition for a binary tree node.
   * public class TreeNode {
   *     int val;
   *     TreeNode left;
   *     TreeNode right;
   *     TreeNode() {}
   *     TreeNode(int val) { this.val = val; }
   *     TreeNode(int val, TreeNode left, TreeNode right) {
   *         this.val = val;
   *         this.left = left;
   *         this.right = right;
   *     }
   * }
   */
  class Solution {
      public boolean isSymmetric(TreeNode root) {
          if (root == null) return true;
          return isMirror(root.left, root.right);
      }
  
      private boolean isMirror(TreeNode left, TreeNode right) {
          if (left == null && right == null) return true;
          if (left == null || right == null) return false;
          if (left.val != right.val) return false;
          return isMirror(left.left, right.right) && isMirror(left.right, right.left);
      }
  }

### 方法二：层序遍历方法

    import java.util.*;
    
    public class Solution {
        int[] tmp = new int[1050]; // 用于存储每一层的节点值
      // 检查数组是否对称
      public boolean check(int[] tmp, int ct) {
          for (int i = 0, j = ct - 1; i < j; i++, j--) {
              if (tmp[i] != tmp[j]) return false;
          }
          return true;
      }
    
      public boolean isSymmetric(TreeNode root) {
          Queue<TreeNode> queue = new LinkedList<>(); // 用于层序遍历的队列
          Queue<Integer> DepthQueue = new LinkedList<>(); // 用于记录每个节点的深度
          if (root == null) return true; // 如果根节点为空，返回true
    
          DepthQueue.offer(0); // 根节点的深度为0
          queue.offer(root);
          int notExist = 101; // 用于表示空节点的值
          int nowDepth = 0, ct = 0; // 当前深度和当前层的节点计数
    
          while (!queue.isEmpty()) {
              int nowD = DepthQueue.poll(); // 当前节点的深度
              TreeNode now = queue.poll(); // 当前节点
    
              if (nowD != nowDepth) { // 如果深度发生变化，检查当前层是否对称
                  if (!check(tmp, ct)) {
                      return false;
                  }
                  ct = 0; // 重置当前层的节点计数
                  nowDepth++; // 更新当前深度
              }
    
              if (now == null) {
                  tmp[ct++] = notExist; // 如果当前节点为空，存储一个特殊值
                  continue;
              } else {
                  tmp[ct++] = now.val; // 存储当前节点的值
              }
    
              // 将当前节点的左右子节点加入队列
              queue.offer(now.left);
              DepthQueue.offer(nowD + 1);
    
              queue.offer(now.right);
              DepthQueue.offer(nowD + 1);
          }
    
          return true; // 如果所有层都对称，返回true
      }
    }
