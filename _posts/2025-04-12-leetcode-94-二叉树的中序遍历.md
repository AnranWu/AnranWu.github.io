## 题目来源
[94. 二叉树的中序遍历 - 力扣（LeetCode）](https://leetcode.cn/problems/binary-tree-inorder-traversal/?envType=study-plan-v2&envId=top-100-liked)

## 题目大意
给定一个二叉树的根节点 `root`，要求返回它的中序遍历结果。中序遍历的顺序是：左子树 -> 根节点 -> 右子树。

## 解题思路及复杂度分析
### 问题分析
题目要求实现二叉树的中序遍历。中序遍历是一种常见的二叉树遍历方式，其遍历顺序为：先遍历左子树，然后访问根节点，最后遍历右子树。这个问题的关键在于如何正确地遍历二叉树并返回遍历结果。

### 方法一：递归方法
递归方法是比较直观的解法，通过递归实现中序遍历。

#### 递归逻辑
1. **递归终止条件**：如果当前节点为空，直接返回。
2. **递归逻辑**：
   - 递归遍历左子树。
   - 访问当前节点，将节点值加入结果列表。
   - 递归遍历右子树。

#### 为什么这种方法可行
- **直观性**：递归方法直接反映了中序遍历的定义，易于理解和实现。
- **正确性**：通过递归，可以确保每个节点的访问顺序符合中序遍历的要求。

### 方法二：迭代方法（使用栈）
迭代方法通过栈来模拟递归的过程，避免递归调用的开销。

#### 迭代逻辑
1. **初始化**：使用一个栈来存储节点，初始化当前节点为根节点。
2. **迭代遍历**：
   - 将当前节点的所有左子节点压入栈，直到没有左子节点。
   - 弹出栈顶节点，访问该节点，并将节点值加入结果列表。
   - 将当前节点的右子节点设置为当前节点，继续上述过程。
3. **结束条件**：当栈为空且当前节点为空时，遍历结束。

#### 为什么这种方法可行
- **高效性**：迭代方法通过栈模拟递归过程，避免了递归调用的开销，适用于大规模数据。
- **正确性**：通过栈，可以确保每个节点的访问顺序符合中序遍历的要求。

### 时间复杂度分析
- 递归方法和迭代方法的时间复杂度均为 \(O(n)\)，其中 \(n\) 是二叉树的节点数。

### 空间复杂度分析
- 递归方法的空间复杂度为 \(O(h)\)，其中 \(h\) 是二叉树的高度。
- 迭代方法的空间复杂度为 \(O(n)\)，因为栈可能存储所有节点。

## 代码
### 方法一：递归方法
```java
import java.util.ArrayList;
import java.util.List;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        inorderHelper(root, result);
        return result;
    }

    private void inorderHelper(TreeNode node, List<Integer> result) {
        if (node == null) return;
        inorderHelper(node.left, result); // 递归遍历左子树
        result.add(node.val); // 访问当前节点
        inorderHelper(node.right, result); // 递归遍历右子树
    }
}
```

### 方法二：迭代方法（使用栈）

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Stack;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Stack<TreeNode> stack = new Stack<>();
        TreeNode current = root;

        while (current != null || !stack.isEmpty()) {
            // 将当前节点的所有左子节点压入栈
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            // 弹出栈顶节点，访问该节点
            current = stack.pop();
            result.add(current.val);
            // 将当前节点的右子节点设置为当前节点
            current = current.right;
        }

        return result;
    }
}
```
